# Glow Tag 🏷️

A pulsing blue tag/label — pure CSS, respects prefers-reduced-motion. Drop-in class.

## What it is
A small pill label with a soft blue glow that gently pulses to draw attention. It is pure CSS (no JS) and automatically stops animating when the visitor has 'reduce motion' enabled. Useful for 'new', 'free' or status labels.

## Usage
```html
<span class="glow-tag">New</span>
```
